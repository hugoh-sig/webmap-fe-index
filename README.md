# WebMap e Dashboard de Análise Geoespacial

Este repositório centraliza os links para duas aplicações focadas em análise geoespacial e visualização de dados:

1.  **WebMap de Índices Espectrais**: Uma aplicação web interativa para análise de índices espectrais em áreas específicas.
2.  **Dashboard de Óxidos de Ferro**: Um painel de controle desenvolvido em R Shiny para a exploração de dados de óxidos de ferro em solos.

## 🚀 Acesso às Aplicações

- **WebMap Interativo**
  - **URL:** [https://webmap-fe-index.netlify.app](https://webmap-fe-index.netlify.app)
  - **Descrição:** Plataforma para visualização e análise de dados geoespaciais, focada em índices espectrais.

- **Dashboard de Óxidos de Ferro**
  - **URL:** [https://hugoh-sig.shinyapps.io/oxidos-ferro/](https://hugoh-sig.shinyapps.io/oxidos-ferro/)
  - **Descrição:** Ferramenta para análise interativa de dados de óxidos de ferro, com gráficos e filtros dinâmicos.

## 🛠️ Tecnologias Utilizadas

- **WebMap:**
  - HTML5, CSS3, JavaScript
  - Netlify (para hospedagem)

- **Dashboard:**
  - R
  - Shiny (framework para aplicações web em R)
  - shinyapps.io (para hospedagem)

## 🎯 Objetivo

O objetivo deste repositório é fornecer um ponto de acesso unificado para as aplicações desenvolvidas, facilitando a demonstração e o compartilhamento dos projetos.
